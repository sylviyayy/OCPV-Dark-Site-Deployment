# 08 — Finish Install and Connect OperatorHub to the Mirror

## Goal

Wait for OpenShift install to complete, then point the cluster at your mirrored operators (IDMS/ITMS + CatalogSource).

## WHERE

Bastion.

```bash
cd /path/to/OCPV-Dark-Site-Deployment
set -a && source .env && set +a
export PATH="${MIRROR_DIR}/clients:${PATH}"
```

## WHY this lab exists

`install-complete` means the control plane and workers formed a cluster.  
Disconnected OperatorHub still needs the **oc-mirror cluster resources** so operators do not try the public internet.

## DO — wait for completion

```bash
# Interactive helper (boots wait + apply resources if present)
./scripts/05-install-ocp-disconnected.sh

# Or manually:
openshift-install agent wait-for install-complete --dir=install-config/ --log-level=info
export KUBECONFIG="${PWD}/install-config/auth/kubeconfig"
oc get nodes
oc get clusterversion
```

## DO — apply mirror resources if not already applied

```bash
# Prefer the copy next to install-config (from script 03) or oc-mirror workdir
oc apply -f install-config/cluster-resources/ \
  || oc apply -f "${OC_MIRROR_WORKDIR}/cluster-resources/"
```

**WHY IDMS/ITMS (not old ICSP):** OpenShift 4.22 disconnected docs prefer ImageDigestMirrorSet / ImageTagMirrorSet generated by oc-mirror v2.

## VERIFY

```bash
export KUBECONFIG="${PWD}/install-config/auth/kubeconfig"
oc get nodes -o wide
# All Ready

oc get co
# Available=True, Progressing=False, Degraded=False (give it time)

oc get imagedigestmirrorset,imagetagmirrorset,catalogsource -A
```

## FAILS IF

| Problem | Symptom |
|---|---|
| Mirror resources missing | Operator installs pull from quay and fail offline |
| Install never completes | Revisit DNS/NTP/registry/MAC labs — do not skip ahead to CNV |
